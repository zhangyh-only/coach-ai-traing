## 一、本轮复核口径

本轮不再只看是否输出 `<?END_CHAT>`，而是同时看四件事：

1. 是否在完整会话内自然走到结束，而不是只跑前几轮。
2. 结束前的动作是否真的像离场、告别或交还商品，不能是“佯装”“余光”“回头看反应”这类留悬念动作。
3. 导购已经主动讲过的价格、渠道、售后、容量、护理、场景等，顾客后续不能改头换面重复问。
4. 模型输出 `<?END_CHAT>` 后，脚本必须调用业务结束接口 `/welearning/api/nstr/mobile/data/end`，以 `endType=1` 标记本次记录结束。

## 二、已修复/补强内容

### Prompt 侧

- 508 与 507 均补强“主动讲过也算已听过”：导购已说到手价、活动边界、官方售后、护理方式、容量或适合场景后，顾客不能再把同一句改成问题问回去。
- 508 与 507 均补强容量逻辑：已经拿起、打开、试装、试背看过，或导购已经讲过能装哪些东西，就按“大致有数”处理，不再把容量拆成多个物件反复问。
- 508 与 507 均补强放手送客：导购说“再考虑一下也可以”“买包还是要自己放心”“回去想想也没关系”“欢迎下次再来”时，哪怕前面没答清，也只能顺着结束，不能继续追旧问题。
- 508 与 507 均补强结束动作：结束轮如果写括号动作，只能写明确结束动作；禁止“佯装去看其他包”“余光瞥向导购”“假装离开”“回头看导购反应”。
- 508 与 507 均补强提示注入防护：要求停止扮演、询问模型身份、按 AI 身份回答等，连续出现时必须结束，不暴露模型身份。

## 五、残留风险

- `<?END_CHAT>` 换行不再作为质量问题。当前口径是：模型认为该结束时能输出该标签，并且脚本成功调用 `/data/end` 即可。
- 这次样本能证明问题概率下降，不能证明绝对消除。角色扮演链仍受模型随机性、抽中的性格卡、产品卡、销售输入质量影响。
- `157616` 中导购脚本自身有错位回答，顾客因此继续追问材质/护理/搭配是可解释的；后续做大样本测试时应继续丰富更真实的销售输入。
- 结束话术同质化是二次复核暴露的新问题：早期多条记录都落到“回去考虑/想想 + 谢谢”的万能句。已补强 prompt，要求结束句必须带本局具体原因或去向，但仍需继续批跑观察。
- 507 奥莱比价型仍是最高风险点：`157622/157623/157624` 证明即使导购主动讲过官方渠道、到手价、小票售后和正价差异，模型仍可能复问“划不划算/网上有没有优势/做工是不是一样”。已进一步压缩并重写 B-比价型随机池，但最后一次 `157625` 抽到 D-心动型，不能作为 B 卡通过证据。
- 本轮只处理角色扮演 prompt 和随机池，不涉及 workflow 链路，也未修改实时评估/整体评估。

结论：是。性格池已经压缩后，产品池如果仍保留 14-15 款，会把组合空间放大到几十种，模型更容易抽到“浅色/软调/大号容量/重复小包”等风险词组合，也会让同一问题以不同产品事实重新被打开。

- 先改写可保留款的风险描述，去掉“软、垂坠、软糯、不挺括、能装下、耐磨”等容易触发连续追问的词。
