# 0009 - 角色问题来源与动态问题槽位

## 背景与问题

在正价场景的真模型回归中，已出现三类表面相反、实际同源的问题：顾客没有形成足够判断就过早成交；为了拉长过程又容易把容量、材质、护理等当成通用问题清单；已问且已答的价格或已完成的试背仍会在后文重开。

旧的固定五阶段能提供进度感，但会把不同性格压成相同的问题顺序。只在性格卡里继续增加顾虑，又会让模型把卡片读成“每项都要问”。因此需要区分“谁决定问什么”和“谁决定还能不能问”。

## 决策

我们决定：**主提示词管问题资格与进度，性格卡管核心判断与先后，产品卡只管体验焦点与主题适配。以最多两个动态问题槽位替代固定阶段清单，并以完整可见对话消费已发生事实。**

具体合同：

- 主提示词只规定哪些主题有资格成为问题、槽位如何关闭、何时体验、形成决定或进入履约；不为所有性格预写同一套问句。
- 性格卡是问题的主来源，负责核心判断、第一关注、问题先后、证据门槛、追问硬度和语气。正价 A- 价值型先确认当前价格与长期价值，D- 心动型先体验上身与搭配，再确认价格；两者不共享一个固定顺序。
- 产品卡的“体验焦点”仅决定现场看/摸/试背的可选动作；“适配主题”只能把性格卡已允许的主题落到当前产品。产品名、尺寸词、包型或可见结构不得自行创造问题。
- 每局最多两个动态问题槽位。每个槽位在心里只有“未触发 / 已提出 / 已回答 / 已放弃”四态；已提出不能回到未触发，已回答或已放弃永久关闭。两个槽位关闭后只形成决定，不新增第三主题。
- 完整可见对话是问过、答过、体验过和已决定的主记录，`rolePlayState` 只查漏与去重。模型某轮 STATE 漏记不能让正文中已问已答的槽位重开。
- 现场目测可以直接发生；拿起、触摸、打开、试背、试装和看镜子必须由导购当轮邀请、允许或协助，避免模型自行跳过接待步骤并压缩轮次。
- 容量不属于问题来源，也不属于产品适配主题。包在眼前时只能通过目测、打开或试装自己的随身物形成体感；不问“能不能装电脑/文件/水杯”或精确尺寸，也不得换物件名重开容量。
- 看包中使用“体验待完成 / 问题槽位待处理 / 可以形成决定”三个动态推进状态。它们每轮从历史派生，不固定问句、不对外输出、不增加第四个 STATE 字段。
- 生成末端执行“只删不增”的检查：删除历史已展示的产品身份、动作同轮叠加的新问题、已有答案的复问，以及成交后的重复决定、理由与新货请求；它不创造阶段或问题。
- 正式 `528/530` 使用精简后的单一运行顺序，并开启 `openThinking` 以执行跨轮历史闭包。配置同步的 `all` 模式必须连同 `openThinking / replaceHistoryState` 顶层字段一起同步并回读，不得只更新卡片数组。
- `531` 只用作 `528` 候选配置的 A/B 实验组；正式验收仍要回到正价 `528` 与奥莱 `530`。
- 奥莱 C-怕踩坑型的当前活动/到手价是购买前必须已知的门槛，使用频率理由不能代替；否则 SA 只说“通勤周末都能用”就可能出现零询价过早成交。
- 当提示词在常见正常对话和业务诱导脚本中已大致稳定时，就达到本轮验收；不为追求随机模型 100% 一致而把商品、性格或话术硬编进 Java 服务。

## 为什么

- 它把“问什么”与“还能不能问”分开：前者保留人设与商品差异，后者统一消费历史事实，才能同时处理过短、乱问和重复。
- 动态推进状态保留了阶段的“这一轮应该向哪里走”，但不带固定问题清单，避免回到历史上无差异的五阶段。
- 产品适配主题比直接把问句写入产品卡更稳定：同一只包在不同性格下可以呈现不同关注，产品卡也不会变成另一个异议库。
- 完整历史为主能兼容现有 STATE 偶发漏记，不需要发布后端或修改数据合同。

## 备选方案

- **恢复固定五阶段与标准异议表**：不选。可以拉长过程，但会让价值型和心动型以同样的顺序问同样的问题。
- **把具体问句全写进产品卡**：不选。商品本身不应决定顾客性格，同一商品也会诱发每局固定的问题脚本。
- **只在性格卡增加更多异议**：不选。没有历史消费机制时，问题越多越容易换皮复问，也会把顾客演成参数考官。
- **Java 派生固定阶段或商品问题**：当前不选。需要部署服务，且容易把模型偶发写错的 STATE 或决定固化；只有提示词稳定性明显达不到常见验收标准时，才重新评估通用、可配置的技术介入。

## 影响与代价

- 正面：不同性格的问题顺序和证据门槛可见；不同产品能改变体验与二级主题；容量与已关闭主题不再进入问题生成。
- 代价：随机卡从纯画像变为带有可执行的核心判断和产品适配标签，每次新增产品需要同步填写体验焦点与适配主题。
- 代价：开启思考模式可能增加单轮延迟与 token 消耗；本轮只证明它和精简 prompt 的组合在小样本中改善了跨轮执行，还需在真实业务自由对话中观测性能与成本。
- 风险：两个槽位和当前价格门槛可能让某些安静性格显得过于爱问。缓解方式是允许 SA 主动说明直接关闭槽位，并让性格卡可以把某个槽位定义为不用问句、只做体验。
